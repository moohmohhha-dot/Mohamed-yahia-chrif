## 4. المونتاج

- **ترتيب:** صوت ← A-roll (Lip-sync بأداة كيما Higgsfield Lipsync / HeyGen / Hedra على صوتك الحقيقي) ← B-roll ← ترجمة ← موسيقى.
- **الانتقالات:** قطع مباشر على الإيقاع + Light sweep فقط في لقطة 1 و4. لا انتقالات عشوائية.
- **الترجمة:** خط عربي عريض (Cairo / Tajawal Bold)، أبيض مع ظل خفيف، في الثلث السفلي فوق منطقة أزرار التيك توك (~25% من الأسفل)، كلمة مفتاحية بالبرتقالي (#FFA53A) أو الأزرق (#3D7BFF).
- **الموسيقى:** Tech / Lo-fi هادئة، 90–100 BPM، -20 dB تحت الصوت، ترتفع شوية في الـ End card.
- **التلوين:** ظلال زرقاء + إضاءة برتقالية دافئة على البشرة، مطابق لصورة المرجع.
- **التصدير:** 1080×1920، 30fps، H.264، ~12 Mbps، AAC 320kbps.
