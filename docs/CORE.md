# ARUMA CORE

**ARUMA CORE** هو القلب المشترك للمنظومة: خادم واحد (`apps/core`) مقسّم إلى وحدات (modules).
كل تطبيقات ARUMA (MB Parfum، MB Beauty، …) وكل خدمات ARUMA تستعمله، ولا يحتوي أي شيء خاص بتطبيق واحد.

## القواعد التي تحمي المستقبل

1. **هوية واحدة لكل شخص في كل ARUMA.** نفس الحساب يدخل به إلى MB Parfum وMB Beauty وغيرهما.
2. **كل وحدة مستقلة.** لكل وحدة مجلد في `apps/core/src/modules/`، ولا تستعمل وحدة أخرى إلا عبر ملفها العام `index.ts`.
   هذه القاعدة **يفحصها اختبار آلي** (`test/module-boundaries.test.ts`): أي مخالفة تُفشل الاختبارات.
   لهذا يمكن لاحقًا نقل أي وحدة إلى خدمة مستقلة دون إعادة كتابة الباقي.
3. **كل تغيير مهم يُسجَّل مرتين في نفس المعاملة:**
   - في **سجل التدقيق** (`audit_logs`): من فعل ماذا، ومتى، ومن أين.
   - في **سجل الأحداث** (`domain_events`): حدث مثل `merchants.verification.approved`. منه ستتغذّى لاحقًا الإشعارات، والـWebhooks، والبحث، والتحليلات، دون تعديل الوحدة التي أنتجت الحدث.
4. **الكتالوج منفصل عن العروض.** المنتج يصف *ماذا* يُباع، و**العرض (offer)** يحدد *مَن* يبيعه، وبأي سعر، وبأي مخزون.
   عدة تجار يمكنهم بيع نفس العطر، والمتجر يعرض تلقائيًا أرخص عرض متوفر في المخزون.
5. **لا يبيع تاجر إلا إذا كان موثَّقًا ونشطًا ومسموحًا له في ذلك المتجر.** هذا الشرط محدد في مكان واحد (`offers/queries.ts`).

## واجهات ARUMA CORE الحالية

### الهوية
| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/v1/auth/register` | إنشاء حساب ARUMA (يُرجع رمز الجلسة) |
| POST | `/v1/auth/login` | الدخول (10 محاولات في الدقيقة لكل IP كحد أقصى) |
| POST | `/v1/auth/logout` | الخروج من الجلسة الحالية |
| GET | `/v1/me` | بيانات المستخدم الحالي |
| GET | `/v1/me/sessions` | الجلسات المفتوحة |
| DELETE | `/v1/me/sessions/:id` | إغلاق جلسة (مثلًا هاتف ضائع) |

الرمز يُرسل في الترويسة `Authorization: Bearer <token>`. يمكن للتطبيق إرسال `X-Device-Id` و`X-Client-Platform` (web/ios/android).

### التجار
كل واجهات التجار والتحقق وفريق المراجعة موثّقة في [MERCHANTS.md](MERCHANTS.md).

### العروض
| الطريقة | المسار | من يستطيع |
|---|---|---|
| GET / PUT | `/v1/merchants/:id/offers` | أعضاء التاجر الموثّق |
| PUT | `/v1/admin/stores/:storeSlug/merchants/:id` | مدير المنصة (السماح بالبيع في متجر + العمولة) |

### المتاجر والكتالوج
انظر [ARCHITECTURE.md](ARCHITECTURE.md). يضاف إليها `GET /v1/stores/:slug/features`.

### أول مدير للمنصة
```bash
DATABASE_URL=... pnpm --filter @aruma/core make-admin you@example.com
```
