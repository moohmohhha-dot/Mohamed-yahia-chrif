# متجر MB Parfum — واجهة الزبائن

الموقع الذي يتسوق منه الزبون. تطبيق مستقل `apps/storefront` (React + Vite)، يتكلم مع ARUMA CORE فقط. لا يعرف شيئًا لا يعرفه أي زائر، وكل القواعد يطبّقها الخادم: الأسعار، المخزون، التوصيل، الدفع عند الاستلام، الصلاحيات.

## الصفحات

| الصفحة | ما فيها |
|---|---|
| الرئيسية | العنوان الرئيسي، العائلات العطرية، الأكثر مبيعًا، أفكار الهدايا، وصل حديثًا |
| كل العطور / البحث | البحث بالعربية والفرنسية والإنجليزية مع إكمال تلقائي. فهم الجمل («عطر رجالي أقل من 9000 دج»)، وتصحيح الأخطاء. فلاتر: العائلة، لمن، العلامة، السعر، المتوفر. الترتيب ([SEARCH.md](SEARCH.md)) |
| صفحة العطر | النفحات (المقدمة، القلب، القاعدة)، الأحجام وأسعارها، السعر لكل 100 مل، البائع وعدد البائعين الآخرين. «يُشترى معًا». آراء المشترين المؤكدين وتوزيع النجوم، وملخص بالذكاء الاصطناعي إن كان مفعّلًا. عطور مشابهة |
| المقارنة | من 2 إلى 4 عطور جنبًا إلى جنب: الأحجام، السعر لكل 100 مل، النوع، النفحات، التقييم. مع الأرخص والأوفر والأعلى تقييمًا |
| أفكار الهدايا | جملة عادية («لأمي، تحب الفانيليا، أقل من 9000 دج») أو اختيارات، فتظهر عطور متوفرة |
| السلة | الكميات، المجموع، البائع لكل منتج |
| إتمام الطلب | 1. الحساب (دخول أو حساب جديد في نفس الصفحة). 2. العنوان: ولاية ← دائرة ← بلدية (58 ولاية، 1541 بلدية). 3. التوصيل لكل بائع وسعره. 4. الدفع عند الاستلام. ثم رمز تأكيد يُرسل بالهاتف |
| طلباتي | القائمة، وصفحة الطلب: مراحل الطلب (جديد ← مؤكَّد ← قيد التجهيز ← مع الموصّل ← تم التسليم)، المنتجات، المبلغ المستحق، العنوان، رقم التتبّع، وإلغاء الطلب حين يسمح الخادم |
| مساعد العطور | يظهر فقط إذا شغّلت ARUMA الذكاء الاصطناعي للمتجر ([AI.md](AI.md)) |

- **اللغات:** العربية افتراضيًا، والفرنسية والإنجليزية. الاتجاه يتغير تلقائيًا.
- **الأجهزة:** الهاتف أولًا، ولا شيء يتجاوز عرض الشاشة.
- **السمة:** الوضع الفاتح والداكن حسب إعداد الجهاز.
- **صور المنتجات:** صور التاجر عندما يرفعها. وإلا قارورة مرسومة بلون وشكل ثابتين لكل عطر، فلا تظهر صورة فارغة ولا صورة لعلامة أخرى.

## البطاقة الذهبية وCIB

الخيار ظاهر في صفحة الدفع بعلامة «قريبًا». خدمة الدفع الإلكتروني جاهزة في الخادم ([PAYMENTS.md](PAYMENTS.md)). تفعيله في الواجهة ينتظر حساب Chargily الحقيقي ومفتاح `checkout.online_payment`.

## نسخة العرض (بلا خادم)

`pnpm build:shop:demo` يبني نسخة كاملة تعمل في المتصفح وحده:
- كتالوج تجريبي من 14 عطرًا بثلاث لغات، بعلامات وبائعين وتقييمات **مختلقة للعرض**، وأسعار معقولة بالدينار؛
- جغرافيا الجزائر الحقيقية (الولايات والدوائر والبلديات)؛
- حسابات وطلبات تُحفظ في المتصفح نفسه؛
- الطلب يتقدّم وحده مع الوقت ليظهر التتبّع؛
- رمز التأكيد: أي 6 أرقام.

شريط في أعلى كل صفحة يقول إنها نسخة عرض. الكود نفسه يعمل في النسختين؛ الفرق فقط في مصدر البيانات (`src/demo/server.ts` يجيب بنفس شكل ARUMA CORE). النسخة الحقيقية لا تحتوي على أي بيانات تجريبية: هذا الجزء يُحذف تلقائيًا عند بنائها.

## الأمان

- **Content-Security-Policy في النسخة الحقيقية:** سكربتات الموقع وحده، والاتصال بخادمه فقط، وخطوط Google.
- **لا بيانات بطاقات** تمر بالموقع.
- **المحفوظ في المتصفح فقط:** رمز الجلسة، والسلة، وقائمة المقارنة.
- **كل طلب** يحمل مفتاح idempotency، فالضغط مرتين لا ينشئ طلبين.

## التشغيل والاختبار

```bash
pnpm dev:shop                         # http://localhost:5175 (يحتاج ARUMA CORE على :3000)
pnpm build:shop:demo                  # نسخة العرض في apps/storefront/dist-demo
node apps/storefront/e2e/run.mjs demo # اختبار المتصفح الكامل على نسخة العرض
node apps/storefront/e2e/run.mjs      # نفس الاختبار على الخادم الحقيقي (يتوقف عند رمز SMS)
```

الاختبار يمر في متصفح حقيقي على:
- العربية واتجاهها، والبحث بجملة وتصحيح الأخطاء؛
- صفحة العطر، والسلة، والمقارنة، والهدايا؛
- الحساب الجديد، والعنوان الجزائري، وخيارات التوصيل؛
- الطلب بالدفع عند الاستلام، والتأكيد، والتتبّع؛
- الفرنسية، وعرض الهاتف، وعدم وجود أخطاء في الصفحة.

## قبل الإطلاق

- **صور حقيقية:** صور العطور يرفعها التجار من مركز التاجر.
- **صفحات قانونية:** شروط البيع، سياسة الخصوصية، سياسة الإرجاع، ومعلومات البائع القانونية.
- **رسائل SMS:** مزوّد حقيقي للرسائل (رمز التأكيد).
- **النشر:** نطاق (مثل mbparfum.dz) وشهادة HTTPS، وخادم يقدّم الموقع والخادم على نفس النطاق (`/v1`).
