# خارطة الطريق

**الهدف النهائي:** ARUMA MARKET، منصة تضم تطبيقات MB التجارية وخدمات ARUMA المشتركة.
الانطلاق من الجزائر، ثم إفريقيا، ثم العالم. التفاصيل التقنية في [ARCHITECTURE.md](ARCHITECTURE.md).

## ✅ المرحلة 0: الأساس (تمت)
- هيكل المشروع (monorepo) واختيار التقنيات
- قاعدة بيانات متعددة المتاجر والتجار والعملات واللغات
- API لقراءة الكتالوج: المتجر، التصنيفات، المنتجات، تفاصيل المنتج
- بيانات تجريبية لـ MB Parfum (3 عطور تجريبية للتطوير فقط)
- اختبارات آلية على قاعدة بيانات حقيقية، ومنها اختبار تشغيل تطبيقين (MB Parfum وMB Beauty) معًا

## ✅ ARUMA CORE: الأساس المشترك (تم)
- الهوية والمصادقة: المستخدمون، طرق الدخول، الجلسات، الأجهزة
- التجار: الموظفون والأدوار، والتوثيق من طرف إدارة المنصة
- عروض التجار: سعر ومخزون لكل تاجر، واختيار أفضل عرض
- سجل التدقيق، سجل الأحداث، وتفعيل الميزات لكل متجر
- الخريطة الكاملة لخدمات ARUMA CORE: [CORE.md](CORE.md)

## ✅ نظام التجار (تم)
- تاجر فرد وتاجر شركة، مع 5 تحققات منفصلة (هاتف، بريد، هوية، نشاط، سحب)
- السجل التجاري غير إلزامي للفرد إلا بقاعدة قانونية لكل دولة ونشاط
- تشفير البيانات والوثائق الحساسة، وقائمة مراجعة لفريق المنصة
- التفاصيل: [MERCHANTS.md](MERCHANTS.md)
- **قبل الإطلاق:** مزوّد SMS/بريد، وتخزين سحابي للوثائق

## ✅ مركز التاجر (تم)
- واجهة ويب بثلاث لغات: لوحة القيادة، المنتجات، الأحجام، العروض، المخزون، التحقق، الإعدادات، السحوبات
- باقي الأقسام ظاهرة مع مرحلة إطلاقها
- سجل المخزون وسجل التدقيق غير قابلين للتعديل أو الحذف على مستوى قاعدة البيانات
- التفاصيل: [MERCHANT_CENTER.md](MERCHANT_CENTER.md)

## ✅ المخزون (تم)
- موجود / محجوز / متاح، عدة مستودعات، تحويل، تنبيه المخزون المنخفض
- حجز عند الطلب، تحرير عند الإلغاء، استهلاك عند الشحن، ومنع البيع الزائد
- استيراد وتصدير CSV/Excel، وواجهة Inventory API
- التفاصيل: [INVENTORY.md](INVENTORY.md)

## ✅ الطلبات (تم)
- طلب لكل تاجر، أسعار من الخادم، حجز المخزون، أمان إعادة الإرسال
- 8 حالات بقواعد انتقال مفروضة في الخادم وقاعدة البيانات، وسجل كامل لا يُعدَّل
- صفحة الطلبات في مركز التاجر
- التفاصيل: [ORDERS.md](ORDERS.md)

## ✅ الدفع (تم)
- خدمة دفع مستقلة: دفع إلكتروني (Chargily: CIB والذهبية)، الدفع عند الاستلام، استرجاع كامل وجزئي، إعادة المحاولة، webhooks، تحقق، idempotency
- **قبل الإطلاق:** حساب Chargily واختبار حقيقي، عنوان HTTPS عام، أسرار في مدير أسرار
- التفاصيل: [PAYMENTS.md](PAYMENTS.md)

## ✅ المالية (تمت)
- دفتر مالي بالقيد المزدوج، غير قابل للتعديل، ومتوازن بقاعدة البيانات
- العمولة 8% كقاعدة قابلة للتغيير (منصة ← متجر ← تاجر)، ورسوم، وفترة حجز 7 أيام
- أرصدة قيد الانتظار والمتاحة، تسويات، تحويلات بمرجع بنكي، رسوم المزوّد، ومطابقة
- **قبل الإطلاق:** محاسب معتمد (الضرائب والفوترة)، حساب بنكي للشركة
- التفاصيل: [FINANCE.md](FINANCE.md)

## ✅ التوصيل (تم)
- العنوان الجزائري: الولاية، الدائرة، البلدية (كل البلديات محمّلة)، الهاتف، ملاحظات التوصيل
- توصيل التاجر بنفسه، شركات التوصيل، الاستلام من المحل؛ ونقاط الاستلام مُجهّزة (مُطفأة)
- مناطق وأسعار يحسبها الخادم، التوصيل المجاني، رقم التتبع، حالات الطرد، وسجل تتبّع لا يُعدَّل
- إطار ربط شركات التوصيل (webhooks موقّعة، مفاتيح مشفّرة)
- **قبل الإطلاق:** حساب Yalidine ووثائق الـAPI لكتابة الربط الآلي؛ حتى ذلك الحين يعمل كل شيء يدويًا
- التفاصيل: [SHIPPING.md](SHIPPING.md)

## ✅ الدفع عند الاستلام (تم)
- تأكيد الطلب برمز SMS أو بمكالمة (مع حد للمكالمات)، والمبلغ المستحق
- حالة التحصيل (عند الناقل / عند التاجر) ودفعات شركات التوصيل مع التحقق
- فشل التوصيل بسبب، والرفض، وإعادة المحاولة حتى الحد
- مؤشرات مخاطر الزبون (بالهاتف والحساب) وإيقاف الدفع عند الاستلام بعد تكرار الرفض أو بقرار من ARUMA
- **قبل الإطلاق:** مزوّد SMS، ومراجعة قانونية لاستعمال سجل الزبون
- التفاصيل: [COD.md](COD.md)

## ✅ المرتجعات ورصيد المتجر (تم)
- طلب الإرجاع بالسبب والصور، رد التاجر خلال 48 ساعة، ومراجعة ARUMA النهائية
- الاستلام من الزبون أو الإيداع، الفحص مع قرار العودة للبيع لكل منتج
- استرداد كامل أو جزئي (إلكتروني تلقائي، أو تحويل مسجّل للدفع عند الاستلام)، استبدال مجاني، رصيد المتجر
- رصيد المتجر: يُمنح ويُستعمل عند الطلب ويُعاد عند الإلغاء، مطابَق مع الدفتر المالي
- **قبل الإطلاق:** سياسة إرجاع مكتوبة ومراجعة قانونية، وإجراء داخلي لتحويلات الاسترداد
- التفاصيل: [RETURNS.md](RETURNS.md)

## المرحلة 1: إطلاق MB Parfum في الجزائر
1. **واجهة متجر MB Parfum**: موقع ويب (عربي/فرنسي/إنجليزي، يدعم الكتابة من اليمين لليسار)
2. **الملف الشخصي والعناوين**: عناوين التوصيل حسب الولاية، التحقق من البريد والهاتف
3. **السلة والطلبات**: السلة، إتمام الطلب، حجز المخزون، حالات الطلب
4. **الدفع والتوصيل في الجزائر**: الدفع عند الاستلام أولًا، أسعار التوصيل حسب الولاية، ثم الدفع الإلكتروني
5. **لوحة التحكم**: إدارة المنتجات والصور والأسعار والمخزون والطلبات

## المرحلة 2: من متجر إلى منصة
- **تعدد التجار (Marketplace)**: لوحة التاجر، العمولات، التسويات
- **ARUMA Points**: نقاط ولاء مشتركة
- **ARUMA Support**: الدعم
- **ARUMA Trust & Safety**: التقييمات ومراقبة التجار
- إطلاق التطبيق الثاني (مثل **MB Beauty**) على نفس المنصة

## المرحلة 3: التوسع
- **ARUMA Logistics / Delivery / Fulfillment**: شحن، مستودعات، مخزون حسب الموقع
- **ARUMA Ads**، **ARUMA AI**، **ARUMA Business**، **ARUMA Developers**
- باقي تطبيقات MB: Style، Home، Tech، Sport، Drive
- دول وعملات إفريقية، ثم الأسواق العالمية (الضرائب، البحث المتقدم)
