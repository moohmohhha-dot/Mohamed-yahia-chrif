# خارطة الطريق

## ✅ المرحلة 0 — الأساس (تمت)
- هيكل المشروع (monorepo) واختيار التقنيات
- قاعدة بيانات متعددة المتاجر والتجار والعملات واللغات
- API لقراءة الكتالوج: المتجر، التصنيفات، المنتجات، تفاصيل المنتج
- بيانات تجريبية لـ MB Parfum (3 عطور تجريبية للتطوير فقط)
- اختبارات آلية على قاعدة بيانات حقيقية

## المراحل المقترحة القادمة (الترتيب قابل للتغيير حسب أولوياتك)
1. **واجهة متجر MB Parfum** — موقع ويب (عربي/فرنسي/إنجليزي، يدعم RTL) لعرض العطور
2. **الحسابات والمصادقة** — تسجيل العملاء، وأدوار المدير والتاجر
3. **السلة والطلبات** — سلة، إتمام الطلب، حجز المخزون، حالات الطلب
4. **الدفع والتوصيل** — الدفع عند الاستلام أولًا (مناسب للجزائر)، ثم الدفع الإلكتروني، وأسعار التوصيل حسب الولاية
5. **لوحة التحكم** — إدارة المنتجات، الصور، الأسعار، المخزون، الطلبات
6. **تعدد التجار (Marketplace)** — لوحة التاجر، العمولات، التسويات
7. **التوسع الدولي** — دول وعملات إضافية، الضرائب، البحث المتقدم
